Excel Lists and Arrays: Multi-value Storage Within Single Cells

Microsoft's new Lists feature allows a single cell to contain multiple discrete values and nested arrays that remain individually accessible for filtering, counting, and calculations—distinct from text concatenation. This is supported by new functions (FLATTEN, HAS, HASANY, HASALL) and works with existing formulas like XLOOKUP, GROUPBY, and PIVOTBY.

Copilot .Rules Feature for Dynamic Instructions

Excel's .Rules feature stores instructions for Copilot that extend beyond simple text directives—enabling non-text rules, dynamic rules that adjust based on cell values, and integration with external data sources. This creates a persistent instruction layer that guides Copilot's behavior contextually within workbooks.

Copilot in Excel Personalization, Rules, and Skills Configuration

Excel's Copilot now supports persistent user preferences (Personalization), custom instruction rules stored within workbooks, reusable automated processes (Skills), and external data connections. These features enable consistent AI behavior across sessions, context-aware instructions, and automation of repetitive Copilot-assisted workflows without requiring OneDrive/SharePoint storage.
