Excel Tables for Dynamic Data Range Management

Converting static ranges to Excel Tables (Ctrl+T) automatically expands formula ranges and PivotTable sources when new rows are added, eliminating manual range updates. Tables also enable structured references in formulas using column names, support dynamic totals that respect filtered data, and integrate with Power Query for automated reporting workflows.

Excel Lists and Arrays in Cells — Native Multi-Value Storage

Excel 365's new Lists and Arrays in Cells feature allows single cells to store multiple typed values, complete 2D arrays, or nested arrays—fundamentally changing cell behavior after 40 years. This enables compact data structuring, in-cell filtering, direct calculations on stored values, and elimination of spilled ranges across worksheets.
