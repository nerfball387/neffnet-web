TRIMRANGE function and dot notation for removing blank cells from spilled ranges

Excel's TRIMRANGE function (or the shorthand dot notation before/after the colon in a range reference like A2:.A100) automatically removes blank cells from dynamic array formulas, eliminating unwanted zeros in spilled results without requiring FILTER wrapping. This works across various scenarios including UNIQUE lists and rolling calculations.
